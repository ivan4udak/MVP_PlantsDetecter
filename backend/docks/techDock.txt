Plant Identifier — Architecture Blueprint v1.0
1. Vision

Мобильное iOS-приложение для определения растений по фото. Позволяет:

Получать структурированный ответ

Работать без регистрации (Guest)

Масштабироваться в enterprise-среде

Поддерживать историю и аудит действий

2. High-Level Architecture

Backend:

Java + Spring Boot

Spring Security

PostgreSQL

Object Storage (S3-compatible)

AI Provider abstraction layer

REST API (gRPC опционально между внутренними сервисами в будущем)

3. User Model

Роли:

ROLE_GUEST: 3 запроса/день

ROLE_USER

ROLE_ADMIN

ROLE_SYSTEM

Guest создаётся автоматически и хранится в users. Лимитируется.

4. Language Strategy

preferred_language хранится в users

передаётся при создании guest

меняется через PATCH /api/v1/users/language

JWT содержит lang как кэш

БД — источник истины

Accept-Language header используется как fallback

5. Security Model

JWT Access (15 мин), Refresh token (7–30 дней)

Role-based access

Soft delete

Rate limiting

Audit через DB triggers

X-Request-ID обязателен в каждом запросе

7. API Contract
Guest

POST /api/v1/session/guest
Request:
{
"deviceId": "ios-uuid",
"preferredLanguage": "ru"
}
Response:
{
"accessToken": "jwt",
"refreshToken": "uuid",
"expiresIn": 86400,
"limitPerDay": 3
}

Auth

POST /api/v1/auth/register
Request: { "email": "...", "password": "..." }
Response: { "userId": "uuid", "createdDate": "..." }

POST /api/v1/auth/login
Request: { "email": "...", "password": "..." }
Response: { "accessToken": "jwt", "refreshToken": "uuid", "expiresIn": 900 }

POST /api/v1/auth/upgrade
Request: { "email": "...", "password": "..." }
Response: обновляет guest → REGISTERED, сохраняет историю

PATCH /api/v1/users/language
Request: { "preferredLanguage": "en" }
Response: обновляет preferred_language пользователя

Plant Analysis

POST /api/v1/plants/analyze
Headers: Authorization: Bearer <token>, X-Request-ID: uuid
Request: multipart/form-data { image, lat (optional), lng (optional) }
Response:
{
"requestId": "uuid",
"isPlant": true,
"confidence": 0.87,
"primaryResult": {
"name": "Betula pendula",
"family": "Betulaceae",
"rarity": "common",
"habitat": "Europe",
"facts": "..."
},
"alternatives": [
{ "name": "Betula pubescens", "confidence": 0.43 }
],
"modelInfo": { "provider": "gpt", "model": "gpt-4.1-mini" },
"processingTimeMs": 1432
}

GET /api/v1/plants/history?page=0&size=20
Response: список кратких записей с requestId, primaryName, confidence, createdDate

GET /api/v1/plants/{id}
Response: полный JSON ответа

DELETE /api/v1/plants/{id}
Soft delete (is_deleted = true)

Technical / Admin Endpoints (ROLE_ADMIN)

GET /api/v1/system/health
GET /api/v1/system/health/deep
POST /api/v1/admin/ai/test
GET /api/v1/admin/stats/usage
GET /api/v1/admin/stats/ai-cost
GET /api/v1/admin/rate-limit/{userId}
POST /api/v1/admin/rate-limit/reset/{userId}
GET /api/v1/admin/audit/{entity}/{id}
GET /api/v1/admin/trace/{requestId}

Error Contract

Все ошибки:

{
"timestamp": "...",
"requestId": "...",
"errorCode": "...",
"message": "...",
"details": null
}

8. Rate Limiting

Guest: 3 запросов/день
Registered: 30+ запросов/день (configurable)
Проверка: count по created_date, позже можно Redis sliding window

9. AI Layer

AIAdapter interface с OpenAIAdapter, YandexAdapter, GigaChatAdapter

Prompt учитывает preferred_language, JSON-only формат, уверенность, альтернативы, проверку “это растение?”

10. Observability

Structured logging (JSON)

Correlation ID

Audit logs

Business metrics

Cost tracking

11. Scaling Strategy

Stage 1: Modular Monolith
